# NeoQBot brand assets

- `neoqbot-logo-original.png` is the preserved 512 × 512 RGBA source image.
- `neoqbot-logo.svg` is the canonical editable vector artwork.
- Web-distribution copies live in `src/neoqbot/web/img/` and are referenced by the console and the
  multilingual README files.

The mark combines a monochrome `NQ` monogram with three connected nodes representing bot, group,
and knowledge orchestration. Keep the geometry, clear space, and black-and-white palette unchanged
when exporting additional sizes.
